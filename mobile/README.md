# SplitCount Mobile App (`/mobile`)

This directory contains the Flutter Android application for **SplitCount**.

## Features Included in Design
- **Local-First Architecture:** Powered by Drift (SQLite) with automatic schema migration strategy.
- **State Management:** Riverpod 2.x for reactive UI and clean separation of concerns.
- **Multi-Payer & Custom Splits:** Split equally, by exact amount, percentages, or parts/shares with multiple payers per expense.
- **Deduplication Engine:** Smart duplicate detection alerts before merging or creating expenses.
- **Visual Analytics:** Category breakdown & trend charts powered by `fl_chart`.
- **Vintage Receipt & CSV Exports:** Generate printable itemized receipt tickets (PDF/PNG) and CSV sheets.
- **QR Code Invites:** Instant group pairing via QR code or invite link.
